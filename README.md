# shared-knowledge

プロジェクト横断で使う共有ナレッジ置き場。

`ideas` が壁打ち・未整理メモなら、ここは **複数リポから参照する前提の整理済み知識**（方針・用語・手順・参照リンク）を置く。

## 使い方

1. 断片はまず [`inbox.md`](./inbox.md) へ追記
2. 定着したら `topics/<slug>/` に移す（1 トピック = 1 フォルダ）
3. 他リポから参照するときは、このリポのパス／URL をリンクで残す

Cursor ではこのフォルダをワークスペースに開くか、作業リポから submodule / 隣ディレクトリとして参照する。

## レイアウト

| パス | 役割 |
|------|------|
| `inbox.md` | 未分類の短い追記先 |
| `inbox/raw/` | 整理前の雑多テキスト（トラブルログなど） |
| `topics/` | 整理済みトピック |
| `refs/` | 外部ドキュメント・URL の短い索引 |
| `AGENTS.md` | エージェント向けの読み方・書き方 |

## ルール

- 秘密情報（鍵・トークン・他人の個人情報）は書かない
- 「なぜそう決めたか」を一文でも残す
- 日付（`YYYY-MM-DD`）を付けると後から追いやすい
- 古くなった記述は消さず、先頭に `outdated:` と代替リンクを足す
