# inbox/raw

整理前の雑多テキストの置き場。あとでエージェントに `topics/` へ整理してもらう前提。

## 置き方

- ファイル名例: `2026-09-19-linux-apt-broken.txt`（日付 + 短い題）
- 中身はコピペのままでよい（チャット全文・コマンド出力・メモ混在 OK）
- 鍵・パスワード・トークン・他人の個人情報は貼る前に消す

## ここから先

1. このフォルダに置く
2. 「`inbox/raw` を整理して」と頼む
3. 定着した知識は `topics/<slug>/` へ。元ファイルは残すか、要約後に消すかはそのとき決める

Linux 運用トラブルは当面ここにまとめてよい。テーマが固まったら `topics/linux-ops/` などを切る。
