# environments

保有マシン・主な実行環境の棚卸し。エージェントや他リポから「どこで何が動くか」を参照する入口。

## 書くもの / 書かないもの

- **書く:** 用途、OS、CPU / RAM、GPU / VRAM、常駐ソフトの有無、最終確認日
- **書かない:** パスワード、鍵、トークン、シリアル、アカウント、個人を特定しやすい詳細

古くなった行は消さず、先頭に `outdated:` と代替を付ける。

詳細は [`machines/`](./machines/) へ。スロットが足りなくなったらマシンごとに 1 ファイル。

## 運用メモ

- 新規マシンはまずこの表に 1 行追加し、必要なら `machines/<id>.md` を切る
- スペック変更・売却・用途変更は確認日を更新する
- 他リポ固有のセットアップ手順は各リポ docs に置き、ここには要約とリンクのみ
