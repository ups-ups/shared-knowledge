# tools

PC 以外の保有ツール（ハード・ソフト・楽器など）の棚卸し。制作・実験で「手元に何があるか」を参照する入口。

マシン一覧は [`../environments/`](../environments/) を見る。

## 書くもの / 書かないもの

- **書く:** 名称、種別、主な用途、接続先マシン（あれば）、最終確認日
- **書かない:** ライセンスキー、シリアル、アカウント、購入価格、個人を特定しやすい詳細

古くなった行は消さず、先頭に `outdated:` と代替を付ける。

## 運用メモ

- 新規はまずこの表に 1 行。メモが増えたら `items/<id>.md` を切る
- 売却・譲渡・ライセンス失効は確認日を更新する
- ソフトのバージョンやプリンタのファームは、運用に効くときだけ書く
